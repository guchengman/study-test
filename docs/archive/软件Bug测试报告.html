1. 测试概述

1.1 测试目标

本次测试针对 v2.1.0 版本的 P0 三件套优化（Excel 题库导入、react-window 虚拟列表、公式渲染兜底）及此前已落地的 UI 一致性整改（T1/T4/T5/T8 视觉层）进行功能验证与全量回归，确保：

  • 新增功能按需求正确工作，不破坏既有流程
  • 既有 73 项单元测试零回归
  • 已识别的 12 项 UI 一致性问题中，已修复项不再复现
  • 高危区域（登录/考试返回/数据持久化）未被触碰

回归测试改了 A，回头再考一遍 B/C/D，确认没被连带弄坏73 项既有用例零回归 = 改新功能没弄坏旧的
