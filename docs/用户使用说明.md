# Study-Test 用户使用说明（使用手册）

> 适用范围：教师、学员、管理员、自学者
> 代码基准：核对于 2026-10-11；文档总索引见 [`docs/README.md`](README.md)
> 配套：线上体验 `www.xiaoyue.shop`；自部署参见 `docs/开发文档.md` 与 `INSTALL.md`

---

## 1. 应用简介

**Study-Test（全科题库）** 是一套「建题 → 练习 → 考试 → 查漏」闭环的在线题库系统，核心能力：

- **多科目题库**：语文 / 数学 / 英语 / Python 等内置科目，也可自建任意科目。
- **三题型**：单选题、多选题、编程/问答题。
- **AI 自动出题**：接入 Gemini、DeepSeek、通义千问等多家大模型，把文本/资料一键变成题目。
- **文档导入**：Word / PDF / Markdown / **Excel (.xlsx/.xls)** / CSV / JSON / 纯文本批量导入，扫描件自动 OCR，公式图片转 LaTeX。
- **在线练习**：模拟考试环境，自动计时、随机出题、即时评分。
- **正式考试**：教师组卷（选题集/分值/限时/开放窗口/及格分）后发布，学员限时作答，服务端权威评分与成绩分析。
- **错题本**：自动记录错题，连对 3 次标记为「已掌握」。
- **学员与共享**：四角色权限 + 三级共享 + 邀请码，适合教培/班级管理。
- **多端**：网页、Windows 桌面（Electron）、Chrome 扩展、Android。

## 2. 快速开始

1. 打开 `www.xiaoyue.shop`（或自部署地址）。
2. 点击右上角「注册」，填写用户名 / 密码（邮箱、手机号可选）。
3. 注册后默认角色为 **独立用户（independent）**，可自建科目、出题、考试。
4. 若要作为**教师**建班，或作为**学员**加入老师，可在「设置 → 角色」中转换（需邀请码或老师手机号）。

## 3. 界面导览

练习主流程为三视图：

| 视图 | 作用 | 主要操作 |
|---|---|---|
| 欢迎页（Welcome） | 选择科目、查看统计 | 新建/进入科目、开始练习或考试、查看错题本 |
| 考试页（Exam） | 答题 | 作答、计时、上一题/下一题、交卷 |
| 结果页（Result） | 成绩与解析 | 查看得分、逐题解析、错题自动归档 |

另有**正式考试**两个页面：学员入口「正式考试」（`/formal-exam`：选卷→作答→成绩）；教师/管理员入口「组卷管理」（`/exams/manage`：创建、发布、分析试卷），见 §8.2。

顶部为 `AppHeader`：搜索、导入、设置、帮助、用户菜单。

## 4. 科目管理

- **新建科目**：欢迎页 →「新建科目」→ 填名称 → 系统根据关键词**智能推荐图标与欢迎语**（如输入「物理」自动配 🔬）。
- **编辑/删除**：科目卡片菜单中操作（至少保留 1 个科目）。
- **共享范围（shareScope）**：
  - `none` 私有（仅自己）
  - `students` 仅我的学员可见（可设白名单）
  - `all` 任意人凭邀请码订阅（自动通过）

> 自建科目上限：自有 10 个 + 共享 10 个。

## 5. 题库管理

### 5.1 手动添加题目
在科目内「添加题目」，选择题型：

| 题型 | 说明 | 答案格式 |
|---|---|---|
| 单选（single） | 4 个选项，1 个正确；判断题用 `['正确','错误']` | 选项字母（如 `A`） |
| 多选（multiple） | 多个正确 | 字母数组（如 `['A','C']`） |
| 编程（programming） | 代码/问答 | 归一化字符串匹配 |

- 题干/选项/解析支持 **Markdown** 与 **LaTeX 公式**（`$...$` 行内、`$$...$$` 块级）。
- 默认分值 5 分，可改。

### 5.2 题目类型与评分
- 单选：选项字母或文本均可判（A ↔ 第一项）。
- 多选：排序后比对答案数组。
- 编程：去空白、统一引号、转小写后判等（**不做代码执行**，请尽量让答案格式规范）。
- ⚠️ **正式考试中编程题不自动判分**，提交后由教师人工评阅，得分以最终发布成绩为准。

## 6. AI 出题

### 6.1 配置 AI Key（首次使用）
1. 右上角「设置」→「AI 配置」。
2. 选择要用的模型（如 `deepseek`），填入对应 **API Key**（Key 仅存你浏览器 localStorage，不上传服务器）。
3. 没 Key 也能用：若服务器配置了 Gemini 代理，登录后即可直接选 Gemini 模型。

> 各平台 Key 申请入口见 §12。Key 安全说明：生产构建不会把 Key 打进网页，配置在「设置」里最稳妥。

### 6.2 生成题目
- **按提示词生成**：在导入框输入「生成 20 道 Python 选择题」，AI 一次性产出题目（默认上限 100 道）。
- **文本/资料转题**：粘贴已有题目或教材段落，AI 解析为标准题目 JSON，并**自动校验答案正确性**（错误答案会被修正）。
- **文件直传（Gemini）**：直接上传 PDF/Word/TXT 给 Gemini 解析。

预览确认后选科目 → 导入。

## 7. 文档导入

入口：欢迎页「导入」。支持格式与流程：

| 格式 | 处理方式 |
|---|---|
| Word (.docx) | mammoth 抽文本+图片；若含公式图且开启「自动识别公式→LaTeX」，逐图并发识别（最多 3，显示进度） |
| PDF | pdfjs 抽文本；**无文本层（扫描件）** 提示 OCR，可选百度 OCR、本地 tesseract、Gemini 视觉或 PaddleOCR |
| Markdown (.md) | 优先按「标准化格式」解析（`### 题型 | 分值:5`）；不匹配则退回 AI 解析 |
| **Excel (.xlsx/.xls)** | 直接结构化解析（只读第一个 sheet）；表头支持中英列名：题型/题目/选项/答案/解析/分值；**题型、题目、答案三列必选**；选项用逗号/分号/竖线或**单元格内换行（Alt+Enter）**分隔；缺省分值 5 |
| CSV / JSON | 直接解析（CSV 列规则与 Excel 一致） |
| 纯文本 (.txt) / Word 旧版 (.doc) | 抽取文本后可交 AI 解析或 OCR |

> 题目多时导入预览采用虚拟滚动，千题级列表不卡顿。

**标准化 MD 模板示例**（可在导入框「下载模板」）：
```markdown
### 单选题 | 分值:5 | 难度:基础 | 知识点:二次函数
题干：已知 $$f(x)=ax^2+bx+c$$ 下列说法正确的是？
A. 开口方向由 b 决定
B. 对称轴为 $x=-\dfrac{b}{2a}$
C. 一定存在零点
D. 函数单调递增
**答案：B**
解析：根据二次函数基础性质可得对称轴公式。
```

**公式识别开关**：导入框中「自动识别公式 → LaTeX」，默认开；未配置任何 AI Key 时自动禁用并提示。

## 8. 在线考试

### 8.1 练习模式（科目内即时开考）
1. 进入科目 →「开始考试」。
2. 系统自动随机出题、开始计时。
3. 逐题作答，可前后翻题。
4. 交卷后进入结果页：看总分、逐题解析，错题自动进错题本。
5. 可随时「退出考试」（进度不保留，按需求谨慎操作）。

### 8.2 正式考试（教师组卷，限时统一考）

**教师/管理员（组卷管理 `/exams/manage`）**：
1. 新建试卷：选题目并设每题分值（总分自动合计）、设限时（分钟）、开放时间段（可选，不填=发布即长期开放）、及格分。
2. 保存为草稿（draft）→「发布」（published）后学员才可见；可关闭（closed）。
3. 答卷列表查看每人成绩，成绩分析页看及格率/分数段；超时未交卷的答卷会被自动收卷（auto_submitted）。
4. 编程题需在此人工评阅给分（提交时不自动判）。

**学员（正式考试 `/formal-exam`）**：
1. 选择科目下已发布的试卷 → 开考（服务端开始计时，页面刷新不丢卷）。
2. 限时内作答，可前后翻题；到时自动收卷。
3. 交卷后立即客观题出分；错题回顾与解析在成绩页查看。
4. **同一试卷可多次参加，取最高分**计入历史。

## 9. 错题本与收藏

- **错题本**：答错的题自动记录；每次重做，连对 **3 次** 自动标记为「已掌握」并移出错题本。
- **收藏**：任意题目可收藏，便于重点复习。
- 错题/收藏可按科目筛选，复习时优先从错题本抽题。

## 10. 学员与共享（教培场景）

### 10.1 四种角色
| 角色 | 权限 |
|---|---|
| admin | 全权，可管理所有用户/科目 |
| teacher | 建科目、管学员、共享科目 |
| student | 绑定老师，见老师共享的科目 |
| independent | 自管，无老师绑定 |

### 10.2 共享三级
- `none` 私有；`students` 仅我的学员（可白名单）；`all` 邀请码订阅（自动通过）。

### 10.3 邀请码
- **注册邀请码**：注册时填写，绑定师生关系。
- **科目邀请码**：教师对科目生成，学员凭码加入（`JoinSubjectModal`）。
- 教师可在「学员管理」中审批待加入学员、移除、重置密码。

## 11. 数据同步 / 导出

- **导出**：「设置 / 数据」→ 导出全部题目、错题、收藏、科目、统计（`/sync/export`）。
- **迁移**：可将本地导出的数据再导入另一账号/环境（`/sync/migrate`）。
- 适合换设备、备份、或教师把题库转交他人。

## 13. 多端使用

| 平台 | 获取/使用 |
|---|---|
| Web | 浏览器访问 `www.xiaoyue.shop` |
| Windows 桌面 | 下载 Electron 便携版 `.exe`，双击运行（无需安装） |

## 14. 常见问题（FAQ）

**Q1：AI 出题提示「需要配置 API Key」？**
A：去「设置 → AI 配置」填入对应模型 Key；或登录后使用服务器 Gemini 代理（需服务端已配 `GEMINI_API_KEY`）。

**Q2：PDF 导入后题目是空的？**
A：可能是扫描件（无文本层）。导入时会提示 OCR，配置百度 OCR AK/SK 或用前端 tesseract 识别；否则请先用 Word 等可复制文本的格式。

**Q3：公式图片没变成 LaTeX？**
A：确认导入框已开启「自动识别公式 → LaTeX」且配置了 AI Key；太小（<100 字节 base64）的图片会被跳过，原图保留。

**Q4：错题怎么才能「掌握」？**
A：在错题本重做，连续答对 3 次自动移除。

**Q5：多选题答案怎么填？**
A：字母数组，如 `['A','C']`；导入时 AI 会自动规范。

**Q6：编程题判分不准？**
A：当前为字符串精确匹配（去空白/统一引号/转小写），答案格式需规范；不做代码执行。

**Q7：能离线用吗？**
A：暂不支持离线；除登录态外业务数据实时从服务器拉取，需联网。

**Q8：忘记密码？**
A：登录页「忘记密码」→ 若绑定邮箱走 EmailJS 验证；或由老师/管理员重置（admin/teacher 有重置权限）。

**Q9：正式考试中途退出/刷新了，答卷还在吗？**
A：在。答卷保存在服务端（限时计时也在服务端），重新进入同一试卷可继续作答；到时未交会自动收卷。同一试卷可多次参加，成绩历史取最高分。

## 15. 术语小抄

| 术语 | 含义 |
|---|---|
| 共享范围 | 科目对谁可见（none/students/all） |
| 邀请码 | 注册绑定师生、或加入科目的凭证 |
| 错题本 | 答错题的自动集合，连对 3 次出列 |

| 标准化 MD | 用 `### 题型 | 分值` 头的批量导题格式 |
